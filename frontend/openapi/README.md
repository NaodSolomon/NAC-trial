# Frontend API contract

`openapi.json` is a normalized snapshot of `backend/dist/openapi.json`. The TypeScript declaration
file at `src/lib/api/generated.ts` is generated from the same document.

After changing a backend route, DTO, response, or OpenAPI decorator:

1. Run `pnpm openapi:generate` in `backend`.
2. Run `pnpm api:generate` in `frontend`.
3. Commit both generated frontend files with the backend contract change.

CI downloads the OpenAPI document generated by the backend job and runs `pnpm api:check`. The check
generates both expected outputs in memory and fails when either committed file is stale.
